# 문자열 계산기

## 📖 개요

커맨드 라인(CLI) 환경에서 동작하는 간단한 문자열 계산기입니다. 주어진 문자열에 포함된 숫자들을 합산하여 결과를 출력합니다.

## ✅ 구현할 기능 목록



- [ ] 쉼표(`,`) 또는 콜론(`:`)을 구분자로 가지는 문자열을 입력받아 각 숫자의 합을 반환한다.

- [ ] 빈 문자열 또는 null 값을 입력할 경우 0을 반환한다.

- [ ] 숫자 하나를 문자열로 입력할 경우 해당 숫자를 반환한다.

- [ ] 커스텀 구분자를 지정할 수 있다.

  - 커스텀 구분자는 `//`와 `\n` 사이의 문자를 사용한다. (예: `//;\n1;2;3`)

- [ ] 문자열 계산기에 음수를 전달하는 경우 예외(Error)를 발생시킨다.

- [ ] 사용자가 문자열을 입력하면 계산 결과를 출력한다.

- [ ] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다. (테스트 코드상 `[ERROR]` 메시지로 확인)

## 🚀 초기 세팅하기

### 1. 의존성 설치

프로젝트를 실행하기 위해 필요한 패키지들을 설치합니다.

```bash
npm install
```

### 2. 애플리케이션 실행 


```bash
npm start
```

실행 후, 콘솔에 문자열을 입력하면 계산 결과를 확인할 수 있습니다.

## ✅ 테스트

Jest를 사용하여 작성된 테스트를 실행합니다.

```bash
npm test
```
